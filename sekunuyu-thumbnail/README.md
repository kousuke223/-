| ファイル | 内容 |
| --- | --- |
| `thumbnail_03.png` / `.jpg` | #3「この先、地獄。」（1280×720） |

YouTube Studio →「コンテンツ」→ 動画の「詳細」→「サムネイル」→「ファイルをアップロード」で設定できます。

## デザイン

### #3：この先、地獄。

クリックされやすさを優先した作り。

- **顔を大きく**：画面の主役はせくぬゆの顔。目を見開いた「ゴクリ…」顔と汗で、緊張感を出す
- **気になる一言**：「この先、地獄。」（#1「死んだら、終わり。」、#2「ネザー、無理。」と同じリズム）を一番大きく
- **見てほしい所をはっきり**：完成したネザーゲートを指さし、赤い矢印でも示す。紫に光るゲートと夕焼けの色の対比で目立たせる
- **左上に英字タイトル**：「MINECRAFT HARDCORE」を石ブロックで組んだ立体文字で（HARDCORE は赤い石）。シリーズ名と番号は「セククラ NO.3」のバッジに
- **要素をしぼる**：小さい画面で読めない飾りは入れない
- 背景には最初に建てた家があり、「最初からゲートまで」の流れが伝わる

### #2：ネザー、無理。

- シリーズ名「マイクラ ハードコア」は #1 と同じ配置・配色
- せくぬゆ（黒髪・白T・黄色いヘッドセット）が、ガストの火の玉から絶叫しながら逃げている
- 体力ハートは残り1.5個で「大ピンチ」

## 作り直すとき

```sh
pip install -r requirements.txt   # Pillow / numpy / scipy
python3 make_thumbnail.py                       # 全エピソードを output/ に書き出し（1枚30〜40秒）
python3 make_thumbnail.py --episode 3           # #3 だけ
python3 make_thumbnail.py --episode 3 --preview # 等倍ですばやく確認（10秒くらい）
```

- 文字を変えたい：各エピソードのファイルの `TEXT`（例：`episodes/ep03_portal.py`）
- ポーズ・カメラ・ゲートや敵の位置：各エピソードの `Scene`
- 表情：`lib/textures.py` の `FACE_GULP`（#3）・`FACE_SCREAM`（#2）（16×16 のドット絵）
- 新しい回を作るときは `episodes/` にファイルを足して、`make_thumbnail.py` の `EPISODES` に登録する
- フォントは初回実行時に Google Fonts から自動でダウンロードします。

| ファイル | 役割 |
| --- | --- |
| `make_thumbnail.py` | どの回を作るか選んで書き出す |
| `episodes/ep03_portal.py` | #3 のシーン（夕焼けとネザーゲート）と文字組み |
| `episodes/ep02_nether.py` | #2 のシーン（ネザーとガスト）と文字組み |
| `lib/voxel.py` | ブロックを描く小さな 3D レンダラー（Zバッファ、テクスチャ、ライト） |
| `lib/world3d.py` | 地形（ボクセル）から見える面だけを取り出す |
| `lib/models.py` | せくぬゆ（プレイヤー）とガストの 3D モデル、ポーズ |
| `lib/textures.py` | ブロック・キャラ・ガスト・炎・ゲートのドット絵テクスチャ、表情 |
| `lib/post.py` | ぼかし・発光・被写界深度・色の仕上げ |
| `lib/overlay.py` | フチ取り文字、石ブロックの英字タイトル、バッジ、矢印、ハート、汗 |
| `lib/fonts.py` | フォントの自動ダウンロード |

## 素材について

- 絵はすべてこのスクリプトで描いたオリジナルです（ブロックの模様・キャラ・ガストもプログラムで作ったドット絵）。
- フォント：Noto Sans JP Black / Dela Gothic One / Press Start 2P（どれも SIL Open Font License で、商用利用OK）
- 英字タイトルは、ドットフォントの1ドットを石ブロック1個にして組んだオリジナルの文字です（公式ロゴの画像は使っていません）。
